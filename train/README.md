# Training Dependencies

This directory contains vendored copies of training frameworks used in the CUWM project.
For a fresh setup, install these from their upstream sources:

- **ms-swift**: https://github.com/modelscope/ms-swift — VLM fine-tuning
- **DiffSynth-Studio**: https://github.com/modelscope/DiffSynth-Studio — Diffusion model training
- **verl**: https://github.com/volcengine/verl — RL training

These directories are included for reproducibility but can be replaced with pip-installed versions.
